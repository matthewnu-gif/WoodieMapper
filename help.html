Woody Wall Mapper Help

Help for Version 1.8.3. Learn what each panel does, when to use it, and how the online/offline architecture works.

Quick Start

Online mode

  1. Switch the Storage panel to Online.
  2. Click Refresh Boards to pull the latest board IDs.
  3. Select the desired board from the dropdown and tap Load.
  4. Pick a problem from the list (or create a new one) before editing or ticking.
  5. Use Save + Cloud whenever you want the new state pushed back online.

Set up a new board

  1. Load a wall photo via the top-left Choose board image file button.
  2. Enter Holds mode to place holds in the right locations and adjust their radii.
  3. Switch to Problems mode, select categories (Start/Hands/Feet/Finish), and label your problem.
  4. Toggle grid feet rules or Kick Board if your wall uses colored foothold grids.
  5. Save locally or online, then optionally export JSON for backup.

Storage Panel

Mode Selector

Choose Local for browser-only storage, or Online to reach Firebase/Supabase. Switch to Online when you want to share boards with other devices.

Refresh Boards, Board List, Board ID

  • Refresh Boards pulls the latest board IDs from Firebase (when Online).
  • The dropdown lists available cloud boards; selecting one fills the Board ID field.
  • Board ID lets you target a specific board name when saving or loading.

Save / Load

Save to Browser and Load work locally; with Online mode, the same buttons trigger Firebase fetch/store plus Supabase image uploads.

Export / Import JSON

Use these buttons to back up or restore a JSON file of holds, problems, circuits, users, and ticks. Helpful for manual versioning or migrating data.

Board Image Upload

Attach a wall image that will be drawn under the holds. When Online mode saves successfully, the file uploads to Supabase storage.

Problems Panel

Problem Selector

Sort problems by grade (ascending/descending) or creation date (newest/oldest). Each entry has quick “Show” and “Delete” controls.

Users & Ticks

Manage climber profiles and track attempts, sessions, and send style (sent/onsight/flash). Use Clear Tick to reset form data.

Problem Creator

  • Set a Problem: name, colour, grade, and category radio buttons let you assign holds to Start/Hands/Feet/Finish.
  • Grid feet toggles (Pink Feel, Blue Feet, Black Feet, Kick Board) store extra rules.
  • Save problem records it locally; Save + Cloud repeats the save then uploads the full board state.
  • Clear selection resets the current hold selections so you can start defining a new problem quickly.

Circuits Panel

Only visible in Circuits mode. Build ordered sequences of holds to create training circuits. Save to list them, or clear selection to restart.

Options & Mode Panels

  • Options: toggle hold IDs, ring visibility, or dim the background image for better contrast.
  • Mode: switch between Holds (add/move/delete holds), Problems (assign holds to categories), and Circuits (sequence holds).

Holds Panel

Displays total hold count, offers radius adjustments, and provides a reset (“Clear all holds”). Use this when laying out a new wall image or cleaning up clutter.

Architecture & Setup

  • Frontend: a single-page app (`index.html`) with vanilla JS handles canvas rendering, UI state, and event wiring.
  • Local persistence: browser localStorage keeps the latest serialized board when saving in Local mode.
  • Firebase: Firestore stores structured board data (holds, problems, circuits, users, ticks). Anonymous auth enables quick write access.
  • Supabase Storage: uploads board image files to the configured bucket; board metadata keeps the filename/URL.
  • Configuration: `config.js` (or the fallback `config.example.js`) must define `window.firebaseConfig` and `window.supabaseConfig` with your project keys.
  • Offline support: an optional service worker (sw.js) caches assets, so the mapper can continue to load even with patchy networks.
Tip: Keep your Supabase bucket policy open for authenticated writes, and make sure Firebase Firestore security rules align with your anonymous usage model.
